# scripts-and-tui

A grab-bag of scripts and terminal user interface (TUI) apps — Python, Bash, Node, and PHP utilities for finance, calendars, content management, and terminal fun. Each script is stored as a markdown file; open one, copy the code, and run it.

**Repository:** [razodin137/scripts-and-tui](https://github.com/razodin137/scripts-and-tui)

## Terminal UIs

- [coffee-shop-tui.md](./coffee-shop-tui.md) / [coffee-shop-tui-version2.md](./coffee-shop-tui-version2.md) — an urwid coffee-shop POS system with rich product catalogs.
- [shop.md](./shop.md) — a simpler urwid storefront.
- [stock-terminalversion3.md](./stock-terminalversion3.md) — a simulated stock market dashboard in curses.
- [scrollcal.md](./scrollcal.md), [python-calscroll.md](./python-calscroll.md), [interactive_calendar.md](./interactive_calendar.md), [interactive_ics_calendar.md](./interactive_ics_calendar.md) — scrollable curses calendars, including an ICS-friendly variant.
- [terminal-slideshow11111.md](./terminal-slideshow11111.md) — a raw-terminal (termios) slideshow player.
- [pure-node-terminal(1).md](./pure-node-terminal(1).md) — a pure-Node TCP terminal with ANSI colors.
- [python-cli.md](./python-cli.md) — a Click-based SQLite content manager CLI.

## Productivity & automation

- [categorize_downloads.md](./categorize_downloads.md) — bash script that sorts your Downloads folder by file type.
- [mouse_click_timer.md](./mouse_click_timer.md) — timed auto-clicker via pyautogui.
- [todo.md](./todo.md) / [todogui.md](./todogui.md) — a todo list, with a PySimpleGUI front-end.
- [newpostmai.md](./newpostmai.md) — create new post files in an inbox directory.
- [installexiftool.md](./installexiftool.md) — installer for ExifTool 13.12.

## Content & publishing

- [whisper-video-metadata.md](./whisper-video-metadata.md) — transcribe videos with Whisper and embed the metadata into MP4s (moviepy + mutagen).
- [yamler-existingposts.md](./yamler-existingposts.md), [yamlyesterscript1.md](./yamlyesterscript1.md) — convert existing posts to YAML front matter.
- [ghostsetup-full.md](./ghostsetup-full.md) — full bash setup for a Ghost CMS install, including a dedicated Linux user.
- [php-dashboard.md](./php-dashboard.md) — a PHP content/analytics dashboard backed by SQLite.
- [setup_bfl_api.md](./setup_bfl_api.md) — scaffolding for calling the BFL API (create request / poll result scripts).
