scripts-and-tui

A grab-bag of scripts and terminal user interface (TUI) apps — Python, Bash, Node, and PHP utilities for finance, calendars, content management, and terminal fun. Each script is stored as a markdown file; open one, copy the code, and run it.

Repository: razodin137/scripts-and-tui

Terminal UIs

  • coffee-shop-tui.md / coffee-shop-tui-version2.md — an urwid coffee-shop POS system with rich product catalogs.
  • shop.md — a simpler urwid storefront.
  • stock-terminalversion3.md — a simulated stock market dashboard in curses.
  • scrollcal.md, python-calscroll.md, interactive_calendar.md, interactive_ics_calendar.md — scrollable curses calendars, including an ICS-friendly variant.
  • terminal-slideshow11111.md — a raw-terminal (termios) slideshow player.
  • pure-node-terminal(1).md — a pure-Node TCP terminal with ANSI colors.
  • python-cli.md — a Click-based SQLite content manager CLI.

Productivity & automation

  • categorize_downloads.md — bash script that sorts your Downloads folder by file type.
  • mouse_click_timer.md — timed auto-clicker via pyautogui.
  • todo.md / todogui.md — a todo list, with a PySimpleGUI front-end.
  • newpostmai.md — create new post files in an inbox directory.
  • installexiftool.md — installer for ExifTool 13.12.

Content & publishing

  • whisper-video-metadata.md — transcribe videos with Whisper and embed the metadata into MP4s (moviepy + mutagen).
  • yamler-existingposts.md, yamlyesterscript1.md — convert existing posts to YAML front matter.
  • ghostsetup-full.md — full bash setup for a Ghost CMS install, including a dedicated Linux user.
  • php-dashboard.md — a PHP content/analytics dashboard backed by SQLite.
  • setup_bfl_api.md — scaffolding for calling the BFL API (create request / poll result scripts).

Finance

  • 2025-01-20-god-account-double-entry.md — double-entry accounting from CSV exports, with live currency conversion to THB.
  • ani-finance.md — a SQLite personal finance tracker on the Desktop.
